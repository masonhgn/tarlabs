# progress_briefs/

Plain-language snapshots of where the effort stands, for Mason to read and push back on.
One per checkpoint, numbered and dated. Each ends by answering the standing
[`accountability_checklist.md`](accountability_checklist.md) in full.

| File | What |
|---|---|
| `accountability_checklist.md` | The standing questions. Edit to add questions; never to remove one quietly. |
| `brief_NN_YYYY-MM-DD.html` | Source of each brief — edit this, not the PDF. |
| `brief_NN_YYYY-MM-DD.pdf` | Rendered brief. |
| `build_brief.py` | `python progress_briefs/build_brief.py brief_01_2026-09-24` rebuilds the PDF from its HTML. |
