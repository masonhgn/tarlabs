Abstract
A well‐liked maneuvering target tracking algorithm is a variable structure multi‐model
(VSMM). One of the crucial elements determining the tracking effect is the successful
model set adaptation (MSA). The ability to further enhance tracking accuracy for the
conventional VSMM method is constrained by the absence of a mechanism to thoroughly
utilise observation and tracking data to optimise MSA. We incorporate the Reinforcement
learning (RL) approach into the MSA procedure to address this issue and provide a
VSMM algorithm based on Monte Carlo (MC) learning. To formulate the challenge of
optimising the number of effective models as a RL problem, we first used the prediction
error, the number of effective model sets, and tracking accuracy to build the models of
the appropriate state space, decision space, and reward. The number of efficient models
was optimised using MC learning, and the entire VSMM algorithm was then created. The
proposed approach was compared to the simulated experiment's five maneuvering target
tracking algorithms. The outcomes demonstrate that the suggested algorithm has a lower
computation scale and accurate tracking accuracy.

INTRODUCTION
The term "maneuvering target" refers to a target whose motion
modes change over time, including steering, accelerating,
stopping suddenly etc. In maneuvering target tracking, the state
of a moving target is continuously estimated using sensor data
and tracking algorithms. Robotics [1], aircraft [2], security
monitoring [3], and other areas all make extensive use of
maneuvering target‐tracking technology, which has drawn
constant attention. Targets that are capable of maneuvering
have a time‐varying and uncertain motion mode. The tracking
outcome will be degraded if the tracker's prior motion model
does not coincide with the actual motion mode [4]. As a result,
one of the challenges of maneuvering target tracking tech-
nology is determining the correct target maneuvering mode.
Traditional maneuvering target tracking technologies can be
loosely split into two types in terms of implementation path:
(1) Adaptive filtering: This method solves the motion mode
estimation problem by estimating the process noise in a given
time window or adaptive model regression [5]. (2) Multi‐model
estimation: Multi‐model probability fusion is used to overcome
the problem of maneuver mode estimation [6, 7]. The adaptive
filtering method, in contrast, has a small calculation scale but
has poor tracking performance for complex maneuvering
operations [8]. Multi‐model estimation technology's robustness
and tracking capabilities are superior, but the requirements for
the prior model design and model probability estimation are
more difficult [9–11].
Multiple model (MM) tracking technologies [12] believe
that if it is difficult to describe the motion pattern of a
maneuvering target with a motion model, a set of motion
models can be used to cover all possible motion patterns of the
target. First, use the multi‐model tracking method to obtain the
Bayesian tracking data for each motion model and then esti-
mate the probability for each model. Finally, the tracking result
is obtained using a weighted fuse of the estimations from

multiple models. As a result, the accuracy of the prior model
set and model probability estimations determines the tracking
quality of the multi‐model tracker. Many multi‐model tracking
approaches have been developed in recent decades, including
general pseudo Bayesian tracking methods [13], interacting
multiple model (IMM) tracking methods [14], and variable
structure multiple model (VSMM) tracking methods [15].
General pseudo Bayesian and IMM always employ a fixed set
of a fixed structure multiple model (FSMM) throughout the
tracked time series. The FSMM technique offers good
computational efficiency, but when the model set is too large, it
causes excessive competition between models, leading to a
deterioration in tracking performance. To avoid the excessive
competition problem, VSMM employs the model set adap-
tion|model set adaptation (MSA) process to pick the effective
model set. In general, the quality of the MSA mechanism
significantly impacts the quality of VSMM tracking results. Two
well‐known MSA approaches are digraph switching (DS) and
activate digraph (AD). To achieve MSA, the DS technique uses
the model group switching mechanism [16, 17], whereas the
AD method uses the likely model set (LMS) mechanism [18].
In recent years, machine learning‐based maneuvering target‐
tracking systems have steadily gained attention [19]. Mahmou-
dreza et al. suggested an autoregressive extended Viterbi model,
which replaces the traditional static model with a dynamic state
transition matrix to improve tracking accuracy [20]. Q‐Learning
Kalman filter (QLKF) learns the filter's process noise and im-
proves the tracking robustness [21]. The Gaussian mixture
probability hypothesis density adaptive turn rate estimation
network utilises an adaptive turning rate estimation network to
address the parameter mismatch issue in the cooperative turning
model [22]. The Elman neural network (ENN) unscented
Kalman filter [23] tracker takes the residual of the prior state
vector and the posterior state vector as input to the ENN and
changes the process noise covariance online to increase the
filter's tracking accuracy. Traditional IMM trackers suffer from
model switching delays and inaccuracies [24]. Moon et al.
developed a deep learning‐assisted estimate technique for IMM
[25], which uses a long short‐term memory (LSTM) network to
determine the suitable maneuver model. Yu et al. predicted the
target's motion trajectory by using an observation vector and an
LSTM network [26]. The error‐ambiguity decomposition
approach is used to develop a new MSA mechanism in the
Error‐Ambiguity Decomposition variable structure multiple
model (EAD‐VSMM) tracker [27]. Aftab et al. proposed the
gaussian process motion tracker [28, 29] as well as the recursive
gaussian process motion smoother [30]. Although several ma-
chine learning‐based maneuvering target‐tracking systems have
been developed, this field is still in its early stages, and many
issues remain unresolved. Few works, for example, combine
machine learning approaches with VSMM methodologies.
Existing VSMM trackers rarely take data accumulation and
learning methods into account when performing MSA. Rein-
forcement learning (RL) [31, 32] is a machine learning technique
that considers both data learning and decision making [33], and
its online decision mechanism has the potential to improve
MSA. As a result, we incorporate RL into the MSA mechanism.
Firstly, the state space, decision space, and revenue models are
built using the state prediction error, the number of activation
models, and the tracking error. Then, the number of effective
models was optimised using Monte Carlo (MC) learning. Finally,
a complete Monte Carlo learning likely model set variable
structure multiple model (MC‐LMS‐VSMM) tracker was built.
The remainder of the paper is structured as follows. The
problem formulation is covered in Section 2. Section 3 in-
troduces the LMS‐VSMM Tracker, which is based on MC
learning. Section 4 contains the simulation results. Section 5
ends with the conclusions.

Monte Carlo learning method
Monte Carlo learning is a well‐known RL technique [33]. Its
steps are as follows: 1) From the environment, the agent
samples a sequence of reward‐related states, actions (de-
cisions), and rewards; 2) The optimal action is chosen based on
the average MC reward of the sampled sequences. The set of
reward‐related states of the agent during its run is denoted by
S = {s1,s2,…,sI}, the action set is denoted by A = {a1,a2,…,
a J}, and the expected reward corresponding to the execution
of action a j ∈A with the reward‐related state si ∈S is marked
by Q(si,a j). Then, at time k, there is a random difference
between the actual reward Rk(sk,ak) and the expected reward
Q(sk,ak) achieved by carrying out action ak with the reward‐
related state sk,
Rkðsk; akÞ ¼ Qðsk; akÞ þ uk
ð11Þ
where sk ∈S, ak ∈A, and uk is the reward noise, which
follows a zero‐mean Gaussian random process.

3.3
|
Monte Carlo learning‐based likely
model set variable structure multiple model
algorithm
Monte Carlo learning is implemented into LMS‐VSMM in the
following steps to determine the effective number for the MSA
module:
1) Model subsets' reward‐related states, actions, and rewards
are modelled with distinct model numbers.
2) MC learning was employed to optimise the number of
effective models in various reward‐related states.
3) The decision findings are used to implement the MC‐based
LMS‐VSMM tracking method online.
3.3.1
|
Decision space
The decision variable to be learnt is the number of activated
models throughout each tracking period. The decision space is
De_Space = {1,2,…,N}, where N is the total number of
models in the prior model set M. The decision space encom-
passes all scenarios in which the number of activated models
ranges from 1 to N.

CONCLUSIONS
The need for a more complex mechanism for learning and
adapting the number of effective models based on tracking and
observation information restricts the traditional variable struc-
ture of MM algorithm's abilities to increase tracking accuracy
further. To overcome this problem, we incorporate MC learning
into the LMS‐VSMM algorithm framework and propose an MC‐
LMS‐VSMM maneuvering target tracking algorithm. Firstly, the
prediction error, number of effective models, and tracking errors
were modelled as reward‐related states, actions, and rewards.
Secondly, the number of effective models was then optimised via
MC learning. Finally, a comprehensive MC‐LMS‐VSMM
tracking algorithm is built. The simulation results reveal that,
when compared to some popular maneuvering target tracking
methods, the MC‐LMS‐VSMM algorithm obtained a satisfying
accuracy. Future research directions include, but are not limited
to, 1) improving the robustness of the MC‐LMS‐VSMM algo-
rithm during mode switching; and 2) investigating VSMM
trackers based on alternative RL approaches.
