1. INTRODUCTION
Jump Markov systems (JMS), as a class of dynamic sys-
tems with inherent mode transition characteristics, exhibit
both Markovian and continuous dynamic behaviors in
their state evolution. They are widely adopted in complex
scenarios such as target tracking and autonomous navi-
gation, where uncertainties in motion mode exist (Wang
et al., 2024; Xu et al., 2024). High-precision JMS state
estimation serves as the critical foundation for enabling
autonomous and intelligent decision-making in fields such
as strategic planning and space exploration. The multiple-
model (MM) estimation method, which performs global
state inference by running a predefined model set in paral-
lel and fusing the conditional estimates of each model, has
now emerged as a representative paradigm for addressing
the joint state-mode estimation problem in JMS (Yang
et al., 2025a).
The MM estimation method has evolved through three
generations of theoretical systems. The autonomous MM
(AMM) architecture establishes the basic framework for
MM estimation by employing parallel recursive Bayesian
filtering and a maximum a posteriori probability weighted
fusion mechanism. However, its independently recursive

approaches such as the adaptive TPM IMM (Xie et al.,

and Chang, 2022). Nevertheless, the intrinsic limitation
of a fixed model set exposes it to the risk of degraded
estimation accuracy or even divergence when there is a
mismatch in the model set. The variable structure interact-
ing MM (VSIMM) theoretically overcomes the limitations
of a preset model set by dynamically adjusting the model
set to construct a time-varying estimation space. However,
the model set adaptive (MSA) mechanism has emerged as
the critical bottleneck hindering its practical engineering
application (Rong Li, 2000).
Existing MSA methods, including model-group switching,
likely-model set, adaptive grid, expected-mode augmen-

fixed structure IMM (Ben et al., 2024; Xu et al., 2016;
Li et al., 2024), can achieve local mode coverage through
parametric variations. However, these methods are con-
strained by structural homogeneity and are therefore only
applicable to scenarios where parameter differences exist

Abstract: Model set adaptation (MSA) is a core issue of variable structure interacting multiple-
model (VSIMM) estimation. The traditional MSA methods are constrained by the requirement
for identical model structures and the accumulation of historical information approximation
errors. This study proposes an adaptive VSIMM filter based on deep Q-network (DQN) for
state estimation in discrete-time jump Markov systems (JMS). a DQN-based MSA is proposed.
First, the analytical solution of VSIMM is derived using Bayesian theory. Second, the proposed
algorithm comprises a Q-network and a target network, leveraging the experience replay
technique to facilitate offline optimization and online deployment of the model selection strategy.
In particular, the designed DQN reward function integrates both model likelihood and model
stability requirements, successfully resolving the mismatch issue between the model set and
the system mode that exists in traditional methods. The numerical simulations for aerial target
positioning using multi-sensor data validate the superior performance of the proposed algorithm
in estimating the states of complex dynamic systems.

3. AN MSA METHOD BASED ON DQN
The VSIMM estimation achieves optimality only when the
model set at each moment aligns perfectly with the true
system mode. The key to attaining this objective resides
in the design and implementation of MSA method. This
section proposes an MSA method grounded in deep Q-
learning. First, let the set of all possible models for the
system be denoted as M, which should aim to cover the
mode space S as comprehensively as possible. The set
M is divided into two subsets: the basic model set Mb
and the candidate model set Mc. Here, Mb is a compact
set consisting of essential models, ensuring fundamental
coverage of the mode space S. The set of models utilized
for state estimation at time k is referred to as the active
model set, denoted as
Mk = Mb ∪Ma

in Ma

quantity. By appropriately designing the state space and
reward function of DQN, the optimal model set is selected
at each moment, thereby enhancing the adaptability and
robustness of the model set.
3.1 Deep Q Network
DQN is a deep reinforcement learning algorithm intro-
duced in 2015 (Mnih et al., 2015). It leverages deep neural
networks to approximate the mapping between an agent’s
states and actions to the value function, specifically the
Q-function, enabling the algorithm to learn the optimal
policy that maximizes the expected cumulative reward.
DQN models the environment as a Markov Decision Pro-
cess (MDP), denoted by M = (S, A, T, γ, R), where S
represents the state space of DQN, A represents the action
space, T denotes the state transition probability, γ is the
discount factor, and R is the reward function. It is worth
emphasizing that in DQN, the state st denotes the current
state of the decision-making agent, which differs from the
state xt in JMS. The policy ρ (a |s) of MDP represents the
probability of selecting action a in a given state s. The goal
of DQN is to learn the optimal policy:

5. CONCLUSION
This paper presents an adaptive VSIMM algorithm based
on DQN for JMS state estimation. Specifically, the reward
function of DQN is defined as the weighted sum of model
set likelihood and model stability. By leveraging offline
training with a dual-network structure and experience
replay mechanism, the Q-network accurately approximates
the true cumulative reward function associated with the
model selection problem. Furthermore, by leveraging on-
line model selection via DQN, autonomous adaptive model
set are realized. This approach overcomes the limitations of
traditional methods that heavily depend on homogeneous
model structures and prior knowledge. The simulations
for target positioning based on multi-sensor fusion have
demonstrated that the proposed method significantly re-
duces positioning errors, thereby establishing an intelli-
gent decision-making framework with a rigorous theoret-
ical foundation for state estimation in complex dynamic
systems.
