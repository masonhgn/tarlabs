# tarlabs

Tar Labs monorepo.

| Directory | What it is |
|---|---|
| [`tarlabs.co/`](tarlabs.co) | The tarlabs.co marketing site — static HTML/CSS/JS, served by nginx, deployed to Fly.io. |
| [`defense/`](defense) | SBIR/STTR topic research: the screening and triage pipeline, its data, and the topic briefs. |

Pushing to `main` deploys the site; see [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
